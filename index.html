gog Personal Mail

A private tool on my own computers.

gog Personal Mail is the name of a private Google sign-in that I use with gog, an open-source command-line program for Google services. It lets the assistant software on my own Macs read my personal Gmail and save draft replies there for me to review. It never sends email.

It is not a service and it is not offered to anyone else. Only my own Google account can sign in to it.
