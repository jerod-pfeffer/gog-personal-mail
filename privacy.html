Privacy policy for gog Personal Mail

Effective 2026-10-24

Who it is for

Only me, the owner of the one Google account that signs in to it. It collects nothing from anyone else.

What it can access

Through Google's gmail.readonly and gmail.compose permissions, it can read the messages in my Gmail account and create and update drafts there. Google bundles sending with the compose permission; on my computers the tool is set up to refuse every command that would send.

Where the information goes

Messages are read on my own computers. They are not stored on any server run for this tool, and they are not sold, shared, or used for advertising. When I ask, messages are shown to an AI assistant (Claude, made by Anthropic) running on my computer, so that it can summarize them and draft replies. Sign-in tokens are kept in the macOS Keychain on my computers.

Google's policy

Use of information received from Google APIs follows the Google API Services User Data Policy.

Removing access

The tool's access can be withdrawn at any time at myaccount.google.com/permissions.

Changes

Any change to this policy is posted on this page with a new effective date.
